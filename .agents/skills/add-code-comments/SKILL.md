# 补充代码注释

为用户指定的代码补充必要注释，只允许修改注释和空白格式，不得改变代码行为。

## 执行规则

1. 读取适用的 `AGENTS.md`。
2. 只处理用户指定的文件、函数、类或目录；未指定范围时先询问。
3. 添加注释前先理解代码、调用关系和数据含义，无法确认时不得猜测。
4. 处理目录时跳过第三方依赖、生成文件、编译产物、缓存和日志。

## 注释要求

所有新增注释统一使用 `//`，不得使用：

- `///`；
- `<summary>`、`<param>`、`<returns>`；
- `/* ... */`；
- 冗长的模板化函数说明。

只注释以下不明显的信息：

- 函数的主要用途；
- 变量的业务含义；
- 单位、范围和坐标系；
- 特殊状态、边界条件和副作用；
- 算法这样处理的原因。

代码和命名已经清楚时，不添加注释。不要逐行翻译代码，也不要要求每个变量和函数都有注释。

一条注释原则上只写一句话，能一句说清楚时不得写成两句。
